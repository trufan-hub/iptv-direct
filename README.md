# IPTV Direct — каталог Rutube с автообновлением

Отдельный от [rutube-auto](https://github.com/trufan-hub/rutube-auto) проект для Android TV и Lazy IPTV Deluxe.

## Готовые плейлисты

- **Полный каталог (до 169 каналов)**: https://trufan-hub.github.io/iptv-direct/direct.m3u
- **Только проверенные сервером потоки**: https://trufan-hub.github.io/iptv-direct/verified.m3u
- **Отчёт проверки**: https://trufan-hub.github.io/iptv-direct/report.json

Генератор запускается каждые 6 часов по GitHub Actions. Данные EPG из IPTVX и EPG.ONE подключаются через `url-tvg` в первой строке плейлиста, что позволяет совместимым плеерам загружать программу.

## Источники и ограничения

В `channels.json` содержатся 169 **разных ID трансляций Rutube**, первоначально извлечённых из публично размещённого Rutube-раздела плейлиста Dimonovich. Для каждого из них один раз сохранена резервная CDN-ссылка (`bootstrap_url`). **Во время последующих сборок плейлист Dimonovich не скачивается**.

Сначала `build.py` запрашивает новый HLS у Rutube Playback API. Если API недоступен или возвращает HTTP 404, он пробует последнюю опубликованную ссылку и начальную CDN-ссылку. Для каждого кандидата проверяется заголовок HLS-манифеста. Проверенные адреса попадают в `verified.m3u`; полный `direct.m3u` дополнительно включает непроверенные адреса, которые могут работать на телевизоре в Латвии, но быть недоступны GitHub runner.

**169 записей — не 169 подтверждённо работающих телеканалов.** Для части каналов Rutube API возвращает 404, и их резервные адреса могут со временем перестать работать. Их полностью независимое автоматическое восстановление не гарантируется. CDN-ссылки не являются постоянными и могут менять подпись; API может вводить ограничения, включая географические и ограничения прав доступа.

## Файлы

- `channels.json` — 169 названий, ID, EPG-ID и начальных резервных URL
- `build.py` — независимая генерация, обновление и проверка HLS
- `.github/workflows/update.yml` — расписание и публикация GitHub Pages
- `docs/direct.m3u` — полный плейлист с резервными адресами
- `docs/verified.m3u` — только потоки, подтвердившие HLS-манифест
- `docs/report.json` — диагностика по каждому каналу без раскрытия его URL

Рабочий проект `rutube-auto` не меняется.
