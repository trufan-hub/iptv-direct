# IPTV Direct — независимый Rutube M3U

Экспериментальный IPTV-проект на собственном каталоге каналов. Скрипт **не скачивает и не читает плейлисты Dimonovich**.

## Структура

- `channels.json` — названия, Rutube live ID и EPG-ID для 12 тестовых каналов
- `build.py` — обращается напрямую к Rutube Playback API и формирует M3U
- `.github/workflows/update.yml` — автоматически обновляет каждые 6 часов
- `docs/direct.m3u` — плейлист (появится после успешного запуска)
- `docs/report.json` — отчёт, скрывающий подписанные HLS-ссылки

## Ограничения

Реальная доступность HLS в Rutube API не гарантирована: возможны географические ограничения и блокировки серверов GitHub. Если API не возвращает **ни одного** URL, скрипт останавливается с ошибкой и не перезаписывает предыдущий плейлист. При частичной ошибке публикует только полученные каналы. Диагностика проверяет содержимое HLS-манифеста, но проверка из GitHub не подтверждает воспроизведение на телевизоре. Источники EPG включаются в M3U посредством `url-tvg`. Публикация прямых ссылок может ограничиваться правилами правообладателей и Rutube.

**Это тестовый проект**, не замена работающего `rutube-auto`.
