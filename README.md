# IPTV Direct — Rutube IPTV с автоматической телепрограммой

Самостоятельный IPTV-проект для Android TV / Lazy IPTV Deluxe. Отдельный от [rutube-auto](https://github.com/trufan-hub/rutube-auto).

## Ссылки для телевизора

**Полный плейлист (169 каналов)**

https://trufan-hub.github.io/iptv-direct/direct.m3u

**Только потоки, подтвердившие HLS-манифест**

https://trufan-hub.github.io/iptv-direct/verified.m3u

**Собственная телепрограмма XMLTV (EPG)**

https://trufan-hub.github.io/iptv-direct/guide.xml.gz

Оба M3U содержат только нашу EPG-ссылку в атрибуте url-tvg первой строки. В Lazy IPTV не нужно вручную добавлять внешние ссылки IPTVX и EPG.ONE. После обновления плейлиста плеер должен зарегистрировать наш источник и загрузить телепрограмму. Автоматическое обновление EPG в самом плеере зависит от его настроек.

## Архитектура

1. channels.json — 169 ID прямых эфиров Rutube и первоначальные резервные CDN-адреса.
2. build.py — запрашивает свежие HLS у Rutube Playback API, проверяет потоки и генерирует docs/direct.m3u и docs/verified.m3u.
3. build_epg.py — получает большие XMLTV-источники IPTVX и EPG.ONE на GitHub Actions, выбирает для наших каналов время и названия передач и публикует наш собственный сжатый docs/guide.xml.gz.
4. Каждый телеканал имеет собственный уникальный tvg-id вида rtv.<rutube_id>; совпадающий channel id используется и в XMLTV.
5. .github/workflows/update.yml — обновляет оба плейлиста и EPG каждые 6 часов, проверяет данные и разворачивает GitHub Pages.
6. docs/report.json и docs/epg_status.json — отчёты по каналам и телепрограмме.

При неудачном получении телепрограммы не публикуется пустая EPG: предыдущая рабочая сборка остаётся на GitHub Pages. У каналов без достоверного расписания передача не выдумывается.

## Важно

- Свой URL EPG не означает независимое создание расписаний передач: исходные фактические данные поступают от внешних XMLTV-провайдеров. Необходимо учитывать условия их использования.
- 169 записей — не гарантия воспроизведения 169 каналов. Некоторые потоки опираются на резервные URL.
- Автоматизация обновляет серверную EPG каждые 6 часов; период повторной загрузки XMLTV на телевизоре зависит от настроек плеера.
- Данные XMLTV находятся в отдельном файле; M3U содержит ссылку на него, а не сами записи программ.

Старый рабочий проект rutube-auto не изменён.
